02

The states and the Resources card

A tile shows one word-sized state plus the memory of its whole process tree. CPU and the per-category share bar live only in the card. Eco = efficiency mode + low priority (always, when parked). Asleep = memory paged out (only under memory pressure). Frozen = suspended (only apps you allowed, only when memory stays tight). A category with no parked windows shows nothing extra.

04

Close category

Hero button Close + CtrlW for the active category, and a right-click entry on a tile for parked ones. Only windows are asked to close (WM_CLOSE), never the processes. The confirm lists the windows, so nothing closes by surprise. Apps that ask "Save?" stay open and are named in a banner afterwards - same banner component as launch problems, calm border instead of red.

05

Signature moment - pick one

One per feature, protected from cleanup. Press play on each. They share the existing pill: click-through, never takes focus, rises from the taskbar edge, tinted in the category colour, reduced motion = fade only.

A · The tile falls asleep

When you leave a category its tile dims, the dot turns into a ring and the memory number counts down to what it keeps. Coming back reverses it. Seen on every switch.
