App Categorizer — Desktop Workspace Organizer

DocCONCEPTS-01 RevA StatusPending your pick

Six different ways to shape the same feature set — categories of apps you open, close, and minimize as a group. All six run on Windows, all six support the same actions underneath; what changes is how much screen space the tool claims and how you reach it day to day. Window chrome below is styled like a real Windows app so you can judge them as if they were on your desktop.

Summon with a hotkey from anywhere, like Spotlight or PowerToys Run. Type or arrow to a category, hit Enter to open it, Shift+Enter to close it. No window sits open at all.

Best when: you switch contexts fast and don't want any UI taking up space.

Lives entirely in the system tray. Click the icon, a compact flyout lists categories with a status dot for what's currently running, click a row to toggle it.

Best when: this should feel like a system utility, not "another app" on your taskbar.
